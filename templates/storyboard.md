# 分镜故事板模板 | Storyboard Templates

漫画、动画和视频分镜头设计模板与规范。

---

## 基础画格模板

### 漫画分镜基本类型

#### 匀分割 Uniform Grid

```
┌─────────┬─────────┐
│         │         │
│   A-1   │   A-2   │
│         │         │
├─────────┼─────────┤
│         │         │
│   B-1   │   B-2   │
│         │         │
└─────────┴─────────┘
适用于：日常场景、对话、静态画面
```

#### 大小分割 Asymmetric Grid

```
┌─────────┬─────────┐
│                 │
│                 │
│      A-1        │
│                 │
├─────────┼─────────┤
│   B-1   │   B-2   │
│         │         │
└─────────┴─────────┘
适用于：重点突出、情绪对比
```

#### 竖条分割 Vertical Strip

```
┌───────┬───────┬───────┐
│       │       │       │
│ A-1   │  A-2  │  A-3  │
│       │       │       │
│       │       ├───────┤
│       │       │  A-4  │
└───────┴───────┴───────┘
适用于：速度感、紧张场景、多视角
```

#### 斜分割 Diagonal Grid

```
┌─────────┼─────────┐
│        /│         │
│      /   │  A-2   │
│    /     │         │
│  /       ├─────────┤
│/         │         │
│  A-1     │  A-3   │
│          │         │
└──────────┴─────────┘
适用于：动感、混乱、战斗场景
```

## 故事板格式规范

### 单格内容模板

```
┌──────────────────────────────────────┐
│                                      │
│           [画面描述]                  │
│                                      │
│                                      │
├──────────────────────────────────────┤
│ 镜头 #: ____    时长: ____秒          │
│ 景别: □远景 □全景 □中景 □近景 □特写   │
│ 角度: □平视 □俯视 □仰视 □倾斜         │
├──────────────────────────────────────┤
│ [对白/旁白]                          │
│                                      │
├──────────────────────────────────────┤
│ [音效/音乐指示]                      │
└──────────────────────────────────────┘
```

### 景别定义

| 景别 | 英文 | 说明 | 情绪效果 |
|------|------|------|----------|
| 远景 | Wide Shot / Establishing | 展示全貌、环境 | 渺小感、距离感 |
| 全景 | Full Shot | 人物全身 | 展示动作、姿态 |
| 中景 | Medium Shot | 膝盖以上 | 自然对话、互动 |
| 近景 | Close-up | 胸部以上 | 表情、情感 |
| 特写 | Extreme Close-up | 局部细节 | 强调、紧张、亲密 |

### 角度定义

| 角度 | 效果 |
|------|------|
| 平视 | 客观、中立 |
| 俯视 | 弱势、无力、从上往下看 |
| 仰视 | 强势、威严、从下往上看 |
| 倾斜 | 不稳定、紧张、混乱 |
| 鸟瞰 | 全局、冷静、规划感 |

## 分镜表示符号

### 转场指示

```
┌─────────┐
│  CUT TO │  → 硬切
├─────────┤
│  FADE IN│  → 淡入
├─────────┤
│FADE OUT │  → 淡出
├─────────┤
│DISSOLVE │  → 叠化/溶解
├─────────┤
│  WIPE   │  → 划像
├─────────┤
│  MATCH  │  → 匹配剪辑
└─────────┘
```

### 运动指示

```
→ 水平移动 (Pan)
↘ 对角移动
↻ 旋转
⟲ 环绕
↔ 推拉镜头 (Dolly)
◎ 摇镜 (Tilt)
```

### 情绪指示

```
[MONTAGE]    → 蒙太奇
[BEAT]       → 停顿/情绪点
[!]          → 爆发点/转折
[?]          → 悬疑点
[♪]          → 音乐节点
```

## 分镜表示例

### 示例：对话场景

```
┌─────────────────────────────────────┐
│ ┌─────┐  "你确定要这么做吗？"        │
│ │     │                             │
│ │ A-1 │  [全景·平视]                 │
│ │     │  咖啡厅内，两人在窗边对坐      │
│ └─────┘  柔和的午间光线               │
├─────────────────────────────────────┤
│ ┌─────┐        "我从来没有          │
│ │     │         像现在这样          │
│ │ A-2 │         确定过。"           │
│ │     │                             │
│ └─────┘  [特写·平视]                │
│           角色A直视镜头              │
├─────────────────────────────────────┤
│ ┌─────┐        ┌─────┐              │
│ │     │        │     │              │
│ │ A-3 │   →    │ A-4 │              │
│ │     │        │     │              │
│ └─────┘        └─────┘              │
│  反应镜头       特写杯子              │
│  角色B低头      (沉默的回应)          │
└─────────────────────────────────────┘
```

### 示例：动作场景

```
┌─────────────────────────────────────┐
│ ┌─────────────────────────────┐     │
│ │          A-1                 │     │
│ │                             │     │
│ │     [远景·俯视]              │     │
│ │     城市屋顶全景              │     │
│ │     角色从左侧跃入            │     │
│ │     ───────────────────→    │     │
│ │     运动轨迹                  │     │
│ └─────────────────────────────┘     │
├─────────────────────────────────────┤
│ ┌───────────┐  ┌───────────┐       │
│ │    A-2    │  │    A-3    │       │
│ │  特写脚   │  │  特写手   │       │
│ │  蹬地     │  │  抓住     │       │
│ └───────────┘  └───────────┘       │
│        ↓             ↓              │
│ ┌─────────────────────────────┐     │
│ │          A-4                 │     │
│ │      [中景·平视]            │     │
│ │      空中翻转               │     │
│ └─────────────────────────────┘     │
├─────────────────────────────────────┤
│ CUT TO: 落地点，水花溅起             │
└─────────────────────────────────────┘
```
