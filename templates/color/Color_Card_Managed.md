## 使用建议

### 按场景选择

| 场景 | 推荐主题 | 原因 |
|------|----------|------|
| 长时间编码 | Catppuccin Mocha | 低对比度，护眼 |
| 演示/截图 | GitHub Dark | 高对比度，清晰 |
| 夜间使用 | Dracula, Nord | 低蓝光 |
| 白天使用 | Solarized Light | 柔和不刺眼 |

### 颜色搭配建议

```css
/* 高对比度组合 */
--bg: #1E1E2E;
--fg: #CDD6F4;
--accent: #89B4FA;

/* 低对比度组合 */
--bg: #2b2b2b;
--fg: #a9b7c6;
--accent: #9876aa;
```
