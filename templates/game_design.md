## 核心循环模板 Core Loop

### 基本游戏循环

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│    ┌─────────┐                                             │
│    │  核心   │                                             │
│    │  循环   │ ←───────────────────────────────────┐       │
│    └────┬────┘                                     │       │
│         │                                          │       │
│         ▼                                          │       │
│    ┌─────────┐    ┌─────────┐    ┌─────────┐      │       │
│    │  行动   │ →  │  反馈   │ →  │  奖励   │ ─────┘       │
│    └─────────┘    └─────────┘    └─────────┘              │
│                                                             │
│                                                             │
│  行动(Action) → 反馈(Feedback) → 奖励(Reward) → 投入(Investment)
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 循环复杂度分级

| 层级 | 描述 | 示例 |
|------|------|------|
| L1 单循环 | 一个核心循环 | 俄罗斯方块：下落→消除→得分 |
| L2 双循环 | 主循环+副循环 | 消消乐：消除循环+步数限制 |
| L3 多循环 | 多个副循环交织 | 阴阳师：战斗+收集+养成 |
| L4 生态循环 | 循环之间相互影响 | 模拟城市：经济+人口+建设 |

## 心流理论应用 Flow Theory

### 心流通道 Flow Channel

```
挑战难度
    ▲
    │     ╭────────────╮
    │    ╱   心流通道   ╲    ← 最佳体验区
    │   ╱               ╲
    │  ╱    ╱╲      ╱╲    ╲
    │ ╱    ╱  ╲    ╱  ╲    ╲
    │╱    ╱    ╲  ╱    ╲    ╲
    ├──────────────────────────────→ 玩家技能
    │ 焦虑      │      无聊
    │(太难)     │      (太简单)
```

### 心流触发器

| 触发器 | 设计要点 |
|--------|----------|
| 明确目标 | 每局/每关有明确目标展示 |
| 即时反馈 | 操作后<100ms有视觉/音效反馈 |
| 技能匹配 | 难度曲线与玩家成长匹配 |
| 控制感 | 玩家感到"这是我的选择" |
| 专注 | 减少干扰，沉浸体验 |

## 数值平衡模板

### 属性公式

```
基础伤害 = 攻击力 × (1 + 加成%) × 技能倍率 × (1 - 减伤%)

暴击伤害 = 基础伤害 × 暴击倍率  (通常 1.5x-2x)

有效生命值(EHP) = 生命值 ÷ (1 - 减伤%)

 DPS = 伤害 ÷ 时间周期
```

### 数值成长曲线

| 曲线类型 | 公式 | 适用场景 |
|----------|------|----------|
| 线性 | y = kx | 稳定可控的成长 |
| 指数 | y = a^x | 快速拉开差距 |
| 对数 | y = log(x) | 后期成长递减 |
| S曲线 | y = 1/(1+e^-x) | 平滑过渡 |
| 平方根 | y = √x | 递减强化 |

```
线性成长      指数成长
    │           │
  y │         y │
    │        ╱  │
    │      ╱    │
    │    ╱      │
    │  ╱        │
    └────────   └────────
       x           x
```

## 玩家类型分类

### Bartle 玩家类型

```
                    │
        杀手        │        社交者
        (Killers)   │        (Socializers)
                    │
────────────┼────────────┼────────────
          │            │
          │            │
          │    探索者   │
          │  (Achievers)│
          │            │
          │            │
────────────────────┼────────────────────
                    │
        成就者      │        冒险者
        (Explorers) │        (World)
                    │
```

| 类型 | 动机 | 设计重点 |
|------|------|----------|
| 杀手 | 击败他人 | PvP、排行榜、竞技场 |
| 社交者 | 与人互动 | 公会、聊天、交易 |
| 探索者 | 发现新事物 | 隐藏内容、彩蛋、世界观 |
| 成就者 | 完成目标 | 任务系统、收集、进度 |

## 教程设计模板

### 渐进式解锁

```
阶段1：基础操作     →  新手引导
  ↓
阶段2：核心玩法     →  功能解锁
  ↓
阶段3：高级内容     →  进阶引导
  ↓
阶段4：社区/竞技     →  自由探索
```

### 新手引导三原则

1. **不打断** - 允许跳过，但提供默认值
2. **可视化** - 箭头/高亮引导，而非文字
3. **可重来** - 失败不惩罚，鼓励尝试
