## 经典构图法则

### 三分法 Rule of Thirds

```
┌─────────┬─────────┬─────────┐
│         │         │         │
│    ●    │         │    ●    │  ← 交叉点为视觉焦点
│         │         │         │
├─────────┼─────────┼─────────┤
│         │         │         │
│         │   [主   │         │
│         │   体]   │         │
│         │         │         │
├─────────┼─────────┼─────────┤
│         │         │         │
│    ●    │         │    ●    │
│         │         │         │
└─────────┴─────────┴─────────┘
```

**适用场景：** 通用摄影、UI设计、海报设计
**效果：** 自然平衡，避免主体居中的呆板感

---

### 黄金分割 Golden Ratio (1:1.618)

```
┌───────────────────────┬─────┐
│                       │     │
│                       │  ϕ  │
│                       │     │
│           ●           ├─────┤
│                       │     │
│                       │     │
└───────────────────────┴─────┘
         1 : 1.618
```

**适用场景：** Logo设计、高端品牌、书籍封面
**效果：** 数学美感，自然界最美比例

---

### 对角线构图 Diagonal Composition

```
┌─────────┬─────────┬─────────┐
│         │         │ \       │
│    ■    │         │  \      │  ← 对角线引导视线
│         │         │   \     │
│         │         │    \ ●  │
│         │         │     \   │
└─────────┴─────────┴──────\──┘
```

**适用场景：** 动态图像、运动主题、速度感表现
**效果：** 创造张力，引导视觉流向

---

### 对称构图 Symmetrical

```
┌───────────────────────────────┐
│         │         │         │
│    ■    │         │    ■    │
│         │         │         │
├─────────┼─────────┼─────────┤
│         │         │         │
│    ■    │    ●    │    ■    │  ← 中轴对称
│         │         │         │
├─────────┼─────────┼─────────┤
│         │         │         │
│    ■    │         │    ■    │
│         │         │         │
└───────────────────────────────┘
```

**适用场景：** 建筑、仪式感设计、正式场合
**效果：** 权威、平衡、庄严

---

### 留白构图 Negative Space

```
┌───────────────────────────────┐
│                               │
│                               │
│         ┌─────────┐           │
│         │         │           │
│         │   ●    │           │  ← 大量留白，突出主体
│         │         │           │
│         └─────────┘           │
│                               │
│                               │
└───────────────────────────────┘
```

**适用场景：** 极简设计、奢侈品牌、艺术海报
**效果：** 呼吸感、高级感、聚焦主体

## 布局网格系统

### 12栏网格 12-Column Grid

```
┌─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│ │ │ │ │ │ │ │ │ │ │ │ │ │  ← 12栏
├─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┼─┤
│ │ │ │ │ │ │ │ │ │ │ │ │ │
│ └─┴─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘ │
│        边距 margin         │
└───────────────────────────┘

常用断点：
- 移动端: 4栏
- 平板:   8栏
- 桌面:  12栏
```

**边距与间距：**
```
┌─────────────────────────────────┐
│           页面边距 24px         │
│  ┌───────────────────────────┐  │
│  │     栏间距 (Gutter)      │  │
│  │  16px / 24px / 32px      │  │
│  └───────────────────────────┘  │
│           页面边距 24px         │
└─────────────────────────────────┘
```

### 8点网格 8pt Grid

```
┌───────────────────────────────┐
│  8px                         │
│ ┌─────────────────────────┐  │
│ │                         │  │
│ │    所有元素尺寸为 8 的    │  │
│ │    倍数：8, 16, 24,     │  │
│ │    32, 40, 48, 64...    │  │
│ │                         │  │
│ └─────────────────────────┘  │
│  8px                         │
└───────────────────────────────┘
```

**适用场景：** 图标设计、UI组件、间距系统
**优势：** 统一感强，便于对齐

## 格式塔原理应用

| 原理 | 定义 | UI应用 |
|------|------|--------|
| 接近法则 | 距离近的元素被视为整体 | 相关按钮紧邻标签 |
| 相似法则 | 相似的元素被视为同类 | 同类信息使用相同颜色/形状 |
| 闭合法则 | 不完整的图形会被脑补完整 | Logo中的负空间设计 |
| 连续法则 | 视线沿线条方向移动 | 引导线设计、内容流 |
| 主体-背景 | 主体与背景分离 | 卡片与背景的层次区分 |
