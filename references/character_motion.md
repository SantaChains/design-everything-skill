# Character Motion | 角色动作

> 本模块包含迪士尼十二原则、动画运动规律与表情动画。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read character_motion

# 搜索特定主题
python scripts/tsv_reader.py --search-module character_motion "挤压"
```

## 运动十二原则

1. 挤压拉伸 2. 预备动作 3. 舞台呈现
4. 连续画/关键帧 5. 跟随/惯性 6. 缓入缓出
7. 弧线运动 8. 次要动作 9. 时间节奏
10. 夸张 11. 扎实形体 12. 吸引力

## 动画周期速查

| 周期 | 内容 |
|------|------|
| 行走周期 | 八帧，重心腿/摆动腿交替 |
| 跑步周期 | 腾空阶段，节奏更快 |
| 跳跃动画 | 预备→起跳→腾空→落地 |
