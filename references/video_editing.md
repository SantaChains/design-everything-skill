# Video Editing | 视频剪辑

> 本模块包含蒙太奇理论、剪辑手法、节奏控制与叙事技巧。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read video_editing

# 搜索特定主题
python scripts/tsv_reader.py --search-module video_editing "蒙太奇"
```

## 剪辑理论速查

| 理论 | 内容 |
|------|------|
| 库里肖夫效应 | 镜头组接创造意义 |
| 蒙太奇四型 | 叙事/表现/对列/反射 |
| 好莱坞连续性 | 180度系统/30度规则/视线匹配 |

## 剪辑手法速查

| 手法 | 用途 |
|------|------|
| J-cut/L-cut | 音频先入/视频先入，流畅衔接 |
| 跳切 | 打破连续性，增加张力 |
| 匹配剪辑 | 动作/图形/构图相似接续 |
| 叠化/黑场 | 淡入淡出，节奏停顿 |
