# UI Components | UI组件

> 本模块包含按钮、输入框、卡片、导航栏、模态框等常见UI组件的设计规范与最佳实践。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read ui

# 搜索特定组件
python scripts/tsv_reader.py --search-module ui "按钮"
```

## 核心组件速查

| 组件 | 状态/要素 |
|------|-----------|
| 按钮 | 默认/悬停/按下/禁用 |
| 输入框 | 默认/空值/聚焦/错误 |
| 卡片 | 容器+标题+内容 |
| 导航 | 顶部/底部标签/侧边抽屉 |
| 模态框 | 遮罩+内容框+关闭机制 |
| 列表项 | 高度固定/左右结构/可点击态 |

## 组件状态设计原则

- **反馈**：每个交互都应有即时反馈
- **一致性**：同类型组件使用相同模式
- **可发现性**：让用户知道可以点击
- **容错性**：防止错误，提供恢复路径
