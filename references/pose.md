# Character Pose | 角色姿势

> 本模块包含人体结构、站姿走姿、动态重心与姿势参考。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read pose

# 搜索特定主题
python scripts/tsv_reader.py --search-module pose "重心"
```

## 基础要素速查

| 要素 | 内容 |
|------|------|
| 比例 | 七头身(成人)/六头身(青少年)/四头身(Q版) |
| 重心 | 单腿承重/重心转移/下沉稳定 |
| 手势三区 | 上区(情绪)/中区(交流)/下区(隐藏) |

## 姿势类型速查

站/走/跑/跳/蹲/坐/卧/战斗/舞蹈/武术
