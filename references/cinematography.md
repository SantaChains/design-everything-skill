# Cinematography | 镜头语言

> 本模块涵盖摄影构图、光影设计与镜头运动。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read cinematography

# 搜索特定主题
python scripts/tsv_reader.py --search-module cinematography "镜头"
```

## 景别系统速查

```
大远景 → 远景 → 全景 → 中景 → 近景 → 特写
(环境)   (全貌)  (人物) (对话) (交流) (强调)
```

## 角度七分法

| 角度 | 效果 |
|------|------|
| 鸟瞰 | 全知/威胁 |
| 俯拍 | 渺小/客观 |
| 平拍 | 平等/尊重 |
| 仰拍 | 威严/压迫 |
| 倾斜 | 不安/混乱 |
| 过肩 | 关系/对话 |
| 主观 | 代入/限制 |
