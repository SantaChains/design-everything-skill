## 核心风格深度解析

### 🖤 极简主义 (Minimalism)

**关键词**：少即是多、负空间、呼吸感、功能至上

**色彩**：黑白灰 + 单色点缀

**代表**：无印良品、苹果、早年谷歌

**设计语法**：
- 去除一切非必要元素
- 留白不是空白，是设计
- 字体选择克制：通常1-2种字体
- 网格系统：严谨精确

**心理机制**：格式塔理论的"简洁性法则"——大脑天然倾向于感知简单、规则的图形

---

### ⚡ 赛博朋克 (Cyberpunk)

**关键词**：霓虹、夜景、高科技低生活、雨夜、故障艺术

**色彩**：霓虹粉/青/紫 + 暗底（#0D0D0D）
典型霓虹：#FF10F0（粉）, #00FFCF（青）, #BD00FF（紫）

**代表**：《银翼杀手》《攻壳机动队》《赛博朋克2077》

**设计语法**：
- 霓虹光效：模拟荧光管辉光（Outer Glow + Inner Glow叠加）
- 故障艺术(Glitch Art)：RGB通道偏移、色差、像素撕裂
- 日语片假名 + 英文混排
- 未来感字体：Roboto Mono / Orbitron / Share Tech Mono
- 扫描线纹理：水平线叠加 + 50%透明度

---

### 🔮 蒸汽波 (Vaporwave)

**关键词**：怀旧、超现实、粉色、雕塑、80s、互联网考古

**色彩**：粉紫蓝渐变 #FF69B4→#8B5CF6 + 青色点缀 #00F5FF

**代表**：Macintosh视觉、超现实雕塑、希腊罗马雕塑+电子合成

**设计语法**：
- 垂坠质感的渐变：#FF69B4 0% → #8B5CF6 50% → #00F5FF 100%
- 古典雕塑 + 网格背景 + 热带植物
- 错误透视：随机拉伸、VHS租赁店美学
- 文字效果：日文片假名 + 罗马音 + 镜像反转
- 纹理：VHS扫描线、噪点、色彩损失（Posterized）

---

### 🎨 孟菲斯设计 (Memphis Design)

**关键词**：几何、撞色、条纹、图案、后现代、反严肃

**色彩**：高饱和撞色：红/黄/蓝/绿/粉 + 黑色描边

**代表**：Ettore Sottsass、孟菲斯集团(1981-1988)

**设计语法**：
- 基础图形：三角形、圆形、波浪线、锯齿边缘
- 点缀元素：圆点、条纹、斜纹、格纹
- 色彩分布：随机感但有节奏
- 黑色描边：2-4px，增加卡通感/手绘感
- 透视：故意使用混乱的3D小透视

---

### 🏛 古典主义 → 新古典主义

**关键词**：对称、庄严、秩序、神话、黄金比例

**代表**：帕特农神庙、米开朗基罗、《维纳斯的诞生》

**色彩**：象牙白、大理石灰、金箔点缀

**设计语法**：
- 严格对称构图
- 黄金螺旋/黄金分割为布局依据
- 人体比例：理想化的头身比（8-9头身）
- 建筑元素：科林斯柱式、山形墙、拱门
- 光影：稳定顶光，强调体积感

---

### 🌊 浮世绘 (Ukiyo-e)

**关键词**：平面化、线条感、季节感、日本美学、物哀

**代表**：葛饰北斋、歌川广重、菱川师宣

**色彩**：传统日本色：
- 红：#E63946
- 蓝：#1D3557
- 绿：#2A9D8F
- 肤：#FFECD2
- 墨：#27272A

**设计语法**：
- 平面色块：物体内部无渐变或极简渐变
- 线条表现：轮廓线明确，内部留白或暗示
- 透视：散点透视（多个灭点）
- 动态感：波浪、飘动的物体
- 季节符号：樱花（春）、蝉（夏）、红叶（秋）、雪（冬）

---

### 🌀 极繁主义 (Maximalism)

**关键词**：多即是多、层次丰富、视觉饱和、华丽、打破边界

**代表**：古斯塔夫·克里姆特、阿尔丰斯·穆夏、当代孟菲斯复兴

**设计语法**：
- 元素堆叠：图案+纹理+图形+照片叠加
- 色彩密度：高饱和+高对比，视觉轰炸
- 金箔/金属质感：金色作为点缀而非主色
- 缠绕的线条/植物纹样
- 视觉节奏：密集→稀疏→密集，制造呼吸感

---

### 💎 新拟态 (Neumorphism)

**关键词**：柔和、逼真、轻盈、触摸感、软UI

**色彩**：低对比度单色（通常#E0E5EC），投影营造凸起/凹陷感

**代表**：现代智能家居界面、高端智能手表UI

**设计语法**：
- 同色系深浅投影：亮面：#FFFFFF (opacity 0.7) / 暗面：#A3B1C6 (opacity 0.7)
- 投影偏移：8px 8px blur 15px
- 边框：无硬边，完全靠光影区分元素
- 局限性：可访问性差，对比度不足

---

### 🪟 玻璃态 (Glassmorphism)

**关键词**：透明、毛玻璃、半透明、模糊、景深

**代表**：iOS系统的控制中心、Windows 11 Fluent Design

**设计语法**：
- `backdrop-filter: blur(20px) saturate(180%);`
- 背景：高饱和度渐变或图片
- 边框：1px solid rgba(255,255,255,0.3)
- 内容：半透明白底 + 模糊 = 玻璃质感
- 阴影：微妙的深色投影增加深度感

---

### 🎲 解构主义 (Deconstruction)

**关键词**：碎片化、反秩序、意外、打破常规、不和谐

**代表**：弗兰克·盖里建筑、大卫·霍克尼的拼贴、保罗·克利的抽象

**设计语法**：
- 元素位移：打破网格，故意偏移
- 碎片化：将完整图形切成不规则碎片
- 色块堆叠：不同色彩/透明度的块随意叠放
- 文字解构：字母拆解、穿插、重叠
- 材质混合：不该在一起的材质硬碰撞

## 风格选择决策树

```
用户需求分析 →

┌─ 情绪优先？
│   ├─ 专业/严肃 → 极简主义 / 新古典主义
│   ├─ 活力/年轻 → 赛博朋克 / 孟菲斯 / 渐变霓虹
│   ├─ 温暖/怀旧 → 蒸汽波 / 浮世绘
│   ├─ 奢华/高端 → 新古典主义 + 金箔 / 解构主义（高段位）
│   └─ 实验/前卫 → 解构主义 / 生成艺术
│
├─ 行业场景？
│   ├─ 科技/数字产品 → 玻璃态 / 赛博朋克 / 极简+玻璃
│   ├─ 时尚/奢侈 → 黑白极简 / 新古典 / 大卫·霍克尼风格
│   ├─ 食品/餐饮 → 暖色调 + 渐变 / 浮世绘
│   ├─ 儿童/玩具 → 孟菲斯 / 高饱和撞色 / 圆润图形
│   └─ 音乐/夜店 → 赛博朋克 / 蒸汽波 / 霓虹
│
└─ 输出媒介？
    ├─ 屏幕/数字 → RGB / 考虑玻璃态/动效
    ├─ 印刷 → CMYK + Pantone + 考虑纸张质感
    ├─ 户外/大幅 → 高饱和 + 远距离可读性
    └─ 社交媒体 → 3:4竖图 / 9:16故事版 / 高冲击色彩
```
