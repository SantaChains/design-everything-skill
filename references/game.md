# Game Design | 游戏设计

> 本模块包含核心循环设计、机制系统、玩家心理与数值平衡。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read game

# 搜索特定主题
python scripts/tsv_reader.py --search-module game "心流"
```

## 核心概念速查

| 概念 | 内容 |
|------|------|
| MDA框架 | 机制→动态→体验 |
| 游戏化八角 | 成就感/所有权/创造性/好奇心/拥有感/社交影响/稀缺性/使命感 |
| 心流理论 | 技能与挑战的平衡 |
| 核心循环 | 目标→挑战→反馈→奖励 |
