# Manga Storyboard | 漫画分镜

> 本模块涵盖画格设计、构图法则、镜头语言与叙事技巧。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read manga_storyboard

# 搜索特定主题
python scripts/tsv_reader.py --search-module manga_storyboard "分镜"
```

## 分镜核心速查

| 概念 | 内容 |
|------|------|
| 时间节奏 | 格数/大小/留白/页面构图 |
| 视线引导 | 角色视线/动作轨迹线/出血格 |
| 对话气泡 | 形状/引线/字体/多层对话 |
| 转场技巧 | 同场景/地点切换/时间流逝/省略 |

## 叙事技巧速查

- **连续动作**：分解动作/动态姿势/暗示动作
- **省略与留白**：格内/格间/页间省略
- **蒙太奇**：时间压缩/概念表达/情绪累积
