# 构图法则 COMPOSITION

## 经典构图法则

| 法则 | 适用场景 | 心理效果 |
|------|----------|----------|
| 三分法 (Rule of Thirds) | 通用，人像/风景/界面 | 自然平衡，避免死板居中 |
| 黄金分割 (Golden Ratio 1:1.618) | Logo/高端设计/建筑 | 植根数学美感，天然舒适 |
| 对角线构图 | 动态/运动/速度感 | 引导视线，制造张力 |
| 对称/镜像 | 庄严/稳定/仪式感 | 权威、完美、催眠式平衡 |
| 框架构图 | 聚焦/强调/纵深感 | 潜意识引导注视框架内主体 |
| 留白构图 | 极简/奢侈/呼吸感 | 高端感，元素被负空间放大 |
| 螺旋构图 | 涡旋/花朵/自然/神秘 | 引导观者深入画面中心 |

## 视觉层级 (Visual Hierarchy)

```
第一眼 → 最大/最亮/最高对比/独特形状
         ↓
第二眼 → 次要元素/引导线指向
         ↓
第三眼 → 细节/补充信息/背景元素

控制工具：
  • 尺寸：越大越重要（但要克制，避免全部放大）
  • 色彩：饱和度越高越抢眼
  • 对比：明暗对比越强越突出
  • 位置：左上>右下（阅读习惯），中心>边缘
  • 隔离：负空间包围的元素天然被突出
  • 重复：重复元素中的异常点会被注意（打破节奏）
```

## 格式塔设计心理学

| 原理 | 定义 | 设计应用 |
|------|------|----------|
| 接近法则 | 距离近的元素被感知为整体 | 按钮与标签靠近，相关内容分组 |
| 相似法则 | 相似元素被感知为同类 | 同类信息使用相同颜色/形状 |
| 闭合法则 | 不完整的图形大脑会自动补全 | Logo用负空间讲故事 |
| 连续法则 | 视线沿连续线条移动 | 用渐变线/引导线引导阅读流 |
| 共同命运 | 一起运动的元素被感知为整体 | 列表项悬停时统一反馈 |
| 图形-背景 | 图形与背景自动分离 | 明确主次，避免视觉混乱 |

## 排版 Typography

### 字体分类速查

```
┌─ 无衬线 Sans-Serif ─────────────────┐
│  现代感 / 干净 / 数字友好           │
│  代表：Helvetica, Arial, Futura    │
│  用途：界面 / 科技 / 极简          │
├─ 衬线 Serif ──────────────────────┤
│  传统感 / 权威 / 文学性            │
│  代表：Times New Roman, Garamond   │
│  用途：正文 / 社论 / 法律          │
├─ 手写 Script ──────────────────────┤
│  人情味 / 创意 / 亲密              │
│  代表：Brush Script, Lobster       │
│  用途：Logo / 标题 / 装饰          │
├─ 等宽 Monospace ──────────────────┤
│  代码感 / 技术 / 精确              │
│  代表：Roboto Mono, Courier        │
│  用途：代码展示 / 数据 / 赛博风    │
├─ 展示/标题 Display ────────────────┤
│  强视觉 / 艺术 / 独特              │
│  代表：Impact, Bebas Neue          │
│  用途：大标题 / 海报 / 品牌         │
└───────────────────────────────────┘
```

### 排版黄金规则

```
1. 行高 = 字号的 1.4~1.8 倍（正文建议 1.5~1.6）
2. 字间距：标题可收紧（-5%~0%），正文用默认或微松
3. 行长：45~75个字符（约中文22~35字），超过则阅读疲劳
4. 层级对比：标题至少是正文的 1.5 倍，建议 2-3 倍
5. 字体数量：同一设计不超过 2-3 种字体
6. 标点挤压：中文排版使用全角标点，与文字同宽
7. 避头尾法则：段落首尾避免单字折行
```

## 导出规范

| 用途 | 格式 | 分辨率/尺寸 | 色彩模式 |
|------|------|-------------|----------|
| Web Hero图 | WebP / JPG | 宽度1920px（按需） | sRGB |

## 设计尺寸基准

**界面设计**：
- 移动端：375×812（iPhone）/ 360×800（安卓通用）
- 桌面端：1440×900（笔记本）/ 1920×1080（桌面）

**间距系统（8pt Grid）**：
- xs: 4px | sm: 8px | md: 16px | lg: 24px | xl: 32px | xxl: 64px

**图标尺寸**：
- 移动端：24×24（主图标）/ 16×16（辅助）
- 桌面端：32×32（主）/ 24×24（辅助）/ 16×16（最小点击目标48×48）
