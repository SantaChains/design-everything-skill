# 设计工作流检查清单

本文档为 design-everything skill 的 Reviewer 模式检查清单。

---

## Stage 1: 需求解析 检查清单

### 必须完成
- [ ] 已提取至少 3 个关键词
- [ ] 已确定目标情绪（信任/活力/奢华/科技/神秘等）
- [ ] 已明确应用场景（网页/App/海报/游戏/视频等）

### 反转模式触发条件
若以下任一条件为真，使用分阶段提问：
- [ ] 用户未提及目标受众
- [ ] 用户未提及情绪目标
- [ ] 用户未提及风格偏好

### 反转模式提问模板
```
1. "这个设计的目标受众是谁？"
2. "希望传达什么情绪？"
3. "有什么风格偏好或禁忌？"
```

---

## Stage 2: 风格提案 检查清单

### 必须完成
- [ ] 已提供 2-3 种风格选项
- [ ] 每种风格有关键词说明
- [ ] 每种风格有色彩特征说明
- [ ] 用户已确认或选择风格方向

### 风格选项质量标准
- [ ] 风格选项之间有差异化
- [ ] 风格选项与需求解析结果匹配
- [ ] 每个风格有代表性案例或视觉描述

---

## Stage 3: 色彩方案 检查清单

### 必须完成
- [ ] 已提供主色（60%）
- [ ] 已提供辅色（30%）
- [ ] 已提供点缀色（10%）
- [ ] 已提供 HEX 色值
- [ ] 已说明配色理由

### 色彩方案质量标准
- [ ] 色彩与目标情绪匹配
- [ ] 色彩与选定风格匹配
- [ ] 色彩对比度满足可访问性要求（WCAG AA）
- [ ] 已标注禁忌色彩

---

## Stage 4: 构图建议 检查清单

### 必须完成
- [ ] 已推荐构图法则
- [ ] 已说明视觉层级（焦点→次级→背景）
- [ ] 已提供布局描述

### 构图建议质量标准
- [ ] 构图法则与应用场景匹配
- [ ] 视觉层级清晰
- [ ] 有焦点引导说明

---

## Stage 5: 元素清单 检查清单

### 必须完成
- [ ] 已列出设计元素
- [ ] 已说明每个元素的作用
- [ ] 已标注优先级（必须/推荐/可选）

### 元素清单质量标准
- [ ] 元素列表完整
- [ ] 优先级标注合理
- [ ] 元素与风格/色彩方案一致

---

## Stage 6: 禁忌提醒 检查清单

### 必须完成
- [ ] 已列出禁忌事项
- [ ] 已说明原因
- [ ] 已提供替代方案

### 禁忌提醒质量标准
- [ ] 禁忌事项具体可操作
- [ ] 原因说明清晰
- [ ] 替代方案可行

---

## 完整输出格式验证

最终输出应包含以下所有部分：

```
1. 【需求解析】→ 关键词、情绪、场景 ✓
2. 【风格提案】→ 2-3种风格选项 ✓
3. 【色彩方案】→ 主/辅/点缀色，含色值 ✓
4. 【构图建议】→ 布局、层级 ✓
5. 【元素清单】→ 需要的设计元素 ✓
6. 【禁忌提醒】→ 应避免什么 ✓
7. 【详细内容】→ TSV数据库相关内容（按需）
```

---

## 质量评分标准

| 维度 | 优秀 | 合格 | 需改进 |
|------|------|------|--------|
| 完整性 | 6/6 阶段完成 | 5/6 阶段完成 | <5 阶段完成 |
| 准确性 | 所有检查点通过 | >80% 检查点通过 | <80% 检查点通过 |
| 实用性 | 可直接执行 | 需少量调整 | 需大幅修改 |
