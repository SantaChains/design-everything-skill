## 配色方法论

### 三色原则 (Trinity Rule)

- **主色**：占画面60%，情绪定调
- **辅色**：占画面30%，层次过渡
- **点缀色**：占画面10%，视觉撬点

### 四配色方案

**A. 类比色 (Analogous)**
间隔30°以内，如蓝+青+绿
→ 和谐、舒适、情绪平稳

**B. 互补色 (Complementary)**
间隔180°，如红+绿、橙+蓝
→ 张力、冲突、视觉刺激
⚡ **警告**：直接互补刺眼，用时降低饱和度或加入中性色隔离

**C. 分裂互补 (Split-Complementary)**
选取互补色两侧的色相，如红的主要互补是绿，取蓝绿和黄绿
→ 活力+和谐并存

**D. 四色矩形 (Tetradic/Rectangle)**
两组互补色，如蓝橙对+黄紫对
→ 丰富、复杂、需强控节奏

## 渐变色系

**前端/数字领域推荐**：
- 同色相渐变：#1E3A8A → #3B82F6 → #93C5FD（信任加深）
- 互补渐变：#FF6B6B → #4ECDC4（冲突到平衡）
- 彩虹渐变：⚠️ 仅用于娱乐/年轻化场景，慎用

**印刷/物理领域**：
- 使用 CMYK 而非 RGB 渐变
- 参考 Pantone 渐变手册

## 专业色值格式

| 格式 | 用途 | 示例 |
|------|------|------|
| HEX | Web/屏幕 | #FF5733 |
| RGB | 数字设计 | rgb(255, 87, 51) |
| RGBA | 半透明 | rgba(255, 87, 51, 0.6) |
| HSL | 色相/饱和/亮度 | hsl(14, 100%, 60%) |
| CMYK | 印刷 | C0 M70 Y100 K0 |
| Pantone | 精准印刷 | Pantone 185 C |
| LAB | 色彩科学 | LAB(60, 45, 50) |

## 色彩空间规范

**屏幕设计**：使用 sRGB IEC61966-2.1（或 Display P3 用于苹果生态）

**印刷设计**：使用 CMYK（ISO Coated v2 或 Gracol）

**档案格式**：PDF/X-1a（印刷）、PNG-24（Web透明背景）、SVG（矢量）
