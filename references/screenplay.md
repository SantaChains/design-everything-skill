# Screenplay | 剧本写作

> 本模块包含结构框架、人物塑造、对话技巧与叙事方法。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read screenplay

# 搜索特定主题
python scripts/tsv_reader.py --search-module screenplay "结构"
```

## 结构模型速查

| 模型 | 内容 |
|------|------|
| 三幕式 | 建置(25%)→对抗(50%)→解决(25%) |
| 节拍器 | 15个节拍 |
| 英雄之旅 | 12个阶段 |

## 人物塑造速查

| 维度 | 内容 |
|------|------|
| 人物弧光 | 正面/负面/平面/对比 |
| 六维度 | 外在/行为/言语/心理/社交/价值观 |
| 对话写作 | 推进/揭示/代替描述/建立关系 |
