# UX Design | 用户体验设计

> 本模块涵盖用户体验理论基础、研究方法、设计原则与评估框架。

## 查询命令

```bash
# 读取完整内容
python scripts/tsv_reader.py --read ux

# 搜索特定理论
python scripts/tsv_reader.py --search-module ux "用户研究"
```

## 核心理论速查

| 理论 | 核心概念 |
|------|----------|
| 用户体验五要素 | 战略→范围→结构→框架→表现 |
| 用户画像 | 数据收集→聚类分析→共性提炼 |
| 用户体验地图 | 角色→触点→行为→情绪 |
| 心智模型 | 用户对产品的内在理解 |

## 设计原则速查

| 原则 | 内容 |
|------|------|
| 希克定律 | 选项越多，决策越慢 |
| 米勒定律 | 7±2 个信息块 |
| 菲茨定律 | 目标越大/越近，越容易点击 |
| 雅各布定律 | 用户希望产品像其他产品一样 |
| 损失厌恶 | 损失的痛苦是等量收益的2倍 |

## 研究方法

- 问卷调查、用户访谈、焦点小组
- 可用性测试、A/B测试、卡片分类
- 用户日志、竞品分析、启发式评估
