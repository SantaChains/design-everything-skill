## 🔍 核心要点速查

### Skill 的本质
> Skill = 能力封装单元 = 清晰、严谨、可执行的指令文档

### 三大黄金法则
1. **单职责优先** - 每个 Skill 只做一件事
2. **边界清晰** - 明确触发条件和退出条件
3. **优雅降级** - 主要功能不可用时有备选方案

### 三级加载系统
- **L1**: frontmatter (始终在上下文,~100 词)
- **L2**: SKILL.md body (触发后加载,<5k 词)
- **L3**: scripts/references/assets (按需加载,无上限)

### 五种设计模式
1. **Tool Wrapper** - 封装外部库/规范
2. **Generator** - 分离结构与内容
3. **Reviewer** - 模块化检查清单
4. **Inversion** - Agent 面试用户
5. **Pipeline** - 硬检查点确保流程

### 六步开发流程
```
理解 → 规划 → 初始化 → 编辑 → 校验 → 迭代
```
