# design-everything | 设计万花筒

> **核心定位**：从美术与创意角度切入，辐射设计思维、配色方法、风格探索、视觉构成，覆盖UI/UX、游戏、漫画分镜、剪辑、剧本、姿势、场景、动作动画等专业领域。

---

## 资产目录 Assets

本skill的`assets/`目录包含以下资源：

| 目录 | 用途 |
|------|------|
| `templates/` | 设计模板（UI组件、配色方案、构图网格、分镜故事板、游戏机制等） |
| `examples/good/` | 优秀设计示例与参考 |
| `examples/bad/` | 设计反例与改进示范 |
| `style-guides/` | 各设计风格的风格指南 |
| `moodboards/` | 情绪板与灵感收集 |

---

## 基础使用

```markdown
---
name: design-everything
description: |
  设计万花筒——从美术与创意角度切入，辐射设计思维、配色方法、风格探索、视觉构成，
  以及UI/UX、游戏、漫画分镜、剪辑、剧本、姿势、场景、动作动画等专业领域。

  【何时触发】
  用户提及以下关键词时激活：
  · 设计类：配色、颜色、风格、设计、美术、构图、视觉、创意、艺术、排版、字体、图形
  · 领域类：UI设计、UX设计、游戏设计、漫画分镜、视频剪辑、镜头语言、剧本写作
  · 术语类：赛博朋克、蒸汽波、极简主义、孟菲斯、浮世绘、黄金分割、格式塔、设计心理学、蒙太奇
---
```

## Skill结构规范

```
skill-folder/
├── SKILL.md (必需)     # YAML frontmatter + Markdown说明
├── scripts/            # 可执行脚本
├── references/         # 参考文档
└── assets/             # 资源文件
    ├── templates/      # 模板
    ├── examples/       # 示例 (good/ | bad/)
    ├── style-guides/   # 风格指南
    └── moodboards/     # 情绪板
```

## 设计输出格式

当用户请求设计时，按以下格式输出：

```
1. 【需求解析】→ 关键词、情绪、场景
2. 【风格提案】→ 2-3种风格选项
3. 【色彩方案】→ 主/辅/点缀色，含色值
4. 【构图建议】→ 布局、层级
5. 【元素清单】→ 需要的设计元素
6. 【禁忌提醒】→ 应避免什么
7. 【详细内容】→ 如涉及专业模块，提供TSV数据库相关内容
```
