## 三、安装与使用

### 3.1 Claude Code 安装

```bash
# 添加市场
/plugin marketplace add alirezarezvani/claude-skills

# 按领域安装
/plugin install engineering-skills@claude-code-skills
/plugin install marketing-skills@claude-code-skills
/plugin install c-level-skills@claude-code-skills

# 安装单个 Skill
/plugin install skill-security-auditor@claude-code-skills
```

### 3.2 多工具转换

```bash
# 转换所有 Skills 到所有工具
./scripts/convert.sh --tool all

# 安装到特定项目
./scripts/install.sh --tool cursor --target /path/to/project
```

## 四、推荐学习路径

### 4.1 入门阶段

1. 从 `template-skill` 开始
2. 理解 SKILL.md 的基本结构
3. 学习 frontmatter 和 body 的写法

### 4.2 实践阶段

1. 安装 `engineering-skills` 尝试
2. 在实际项目中应用
3. 观察触发和执行效果

### 4.3 进阶阶段

1. 学习 `self-improving-agent` 模式
2. 理解高级设计模式
3. 掌握评估与优化方法

### 4.4 精通阶段

1. 创建自定义 Skills 并贡献社区
2. 构建完整的 Skill 体系
3. 分享最佳实践
