## 极简主义 Minimalism

### 核心特征

| 属性 | 规范 |
|------|------|
| 色彩 | 黑白灰为主，最多一个强调色 |
| 形状 | 简单几何，无装饰 |
| 空间 | 大量留白，呼吸感强 |
| 字体 | 无衬线，简洁 |
| 材质 | 纯色平面，无纹理 |

### 色彩规范

```
主色    ████████████████████████████ #000000 (纯黑)
背景色  ████████████████████████████ #FFFFFF (纯白)
灰度1   ████████████████████████████ #333333
灰度2   ████████████████████████████ #666666
灰度3   ████████████████████████████ #999999
强调色  ████████████████████████████ #0066FF (可选蓝)
```

### 设计要点

```
✓ 删减到不能再删
✓ 每个元素都有存在的理由
✓ 留白不是浪费，是呼吸
✓ 一行一个信息
✗ 避免：过度装饰、视觉噪音
✗ 避免：多色、渐变
✗ 避免：小字号、拥挤布局
```

### 代表作品

- Apple 产品设计
- 无印良品
- Dieter Rams 设计
- 瑞士平面设计

## 赛博朋克 Cyberpunk

### 核心特征

| 属性 | 规范 |
|------|------|
| 色彩 | 霓虹色 + 深色背景 |
| 光效 | 泛光、发光、渐变 |
| 纹理 | 故障艺术、噪点、扫描线 |
| 元素 | 科技感线条、几何 |
| 情绪 | 未来感、叛逆、神秘 |

### 色彩规范

```
背景色   ████████████████████████████ #0D0D0D (深黑)
主色1   ████████████████████████████ #FF10F0 (霓虹粉)
主色2   ████████████████████████████ #00FFFF (霓虹青)
强调色   ████████████████████████████ #FFFF00 (警示黄)
辅助色   ████████████████████████████ #FF0080 (霓虹紫)
文字色   ████████████████████████████ #E0E0E0 (浅灰)
```

### 视觉元素

```
✓ 霓虹发光效果 (box-shadow: 0 0 10px #FF10F0)
✓ 故障艺术叠加 (glitch effect)
✓ 网格/扫描线纹理
✓ 未来感字体 (Orbitron, Rajdhani)
✓ 倾斜/破碎的排版
✗ 避免：暖色调、自然元素
✗ 避免：柔和边缘、圆形过多
```

### 纹理应用

```
噪点叠加     ░░▒▒▓▓██░░▒▒▓▓██  透明度 5-15%
扫描线       ════════════════  水平线叠加
故障偏移     RGB通道分离位移   2-4px偏移
```

### 代表作品

- 《银翼杀手2049》
- 《赛博朋克2077》
- 《攻壳机动队》
- Blade Runner 风格

## 孟菲斯 Memphis

### 核心特征

| 属性 | 规范 |
|------|------|
| 色彩 | 高饱和、撞色 |
| 形状 | 几何图案、自由曲线 |
| 元素 | 装饰性图案、黑色描边 |
| 情绪 | 活泼、反叛、创意 |

### 色彩规范

```
主色1   ████████████████████████████ #FF6B6B (珊瑚红)
主色2   ████████████████████████████ #4ECDC4 (青绿)
主色3   ████████████████████████████ #FFE66D (明黄)
主色4   ████████████████████████████ #95E1D3 (薄荷)
点缀色   ████████████████████████████ #222222 (纯黑)
背景色   ████████████████████████████ #FFFFFF
```

### 图案系统

```
几何图案：
□ ■ ● ▲ ★ ← 基本图形
┼ ╳ ═ ╔ ╗ ╚ ╝ ← 线条装饰
波纹 ╿ ╍ ╎ ╏ ← 随机线条

组合示例：
┌─────────────────────────────────┐
│  ★  ■  ●  ★  ■  ●  ★  ■  ●  │
│    ════════════════════        │
│  ●  ★  ■  ●  ★  ■  ●  ★  ■  │
│    ════════════════════        │
│  ★  ■  ●  ★  ■  ●  ★  ■  ●  │
└─────────────────────────────────┘
```

### 设计要点

```
✓ 高饱和撞色组合
✓ 黑色粗边框描边 (2-4px)
✓ 随机几何图案排列
✓ 点线面混合使用
✓ 活泼的排版布局
✗ 避免：统一、对齐、规整
✗ 避免：自然、有机形状
```

### 代表作品

- Ettore Sottsass 设计
- Masanori Umeda
- 80年代后现代主义

### 经典元素

## 玻璃拟态 Glassmorphism

### 核心特征

| 属性 | 规范 |
|------|------|
| 效果 | 毛玻璃、半透明 |
| 背景 | 渐变或图片 |
| 边框 | 细白边框 |
| 阴影 | 柔和投影 |

### 样式规范

```css
/* 玻璃效果参数 */
backdrop-filter: blur(20px);
background: rgba(255, 255, 255, 0.1);
border: 1px solid rgba(255, 255, 255, 0.2);
border-radius: 16px;
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
```

### 配色参考

```
玻璃层   rgba(255, 255, 255, 0.15)
边框     rgba(255, 255, 255, 0.3)
阴影     rgba(0, 0, 0, 0.1)
内容文字  rgba(255, 255, 255, 0.9) 或 #FFFFFF
背景建议：渐变或模糊图片
```

### 设计要点

```
✓ 背景需要足够丰富（渐变/图片）
✓ 模糊强度 10-30px
✓ 边框细而半透明
✓ 圆角适中 12-24px
✗ 避免：纯色背景（效果不明显）
✗ 避免：边框过粗
```

### 代表作品

- iOS毛玻璃效果
- macOS Big Sur 系统UI
- 微软Fluent Design
