# UI/UX 设计示例 | Good Examples

优秀UI/UX设计案例，遵循可用性原则和用户体验最佳实践。

---

## 按钮设计

### ✅ 优秀示例：明确的层级与反馈

**特征：**
- 主按钮使用填充色，次按钮使用描边或ghost样式
- hover/focus/active 状态反馈清晰
- 禁用状态有明确的视觉降级处理
- 按钮内边距充足（16px水平，8px垂直）
- 圆角统一（4px-8px）

**案例：**
```
┌──────────────┐
│  Primary     │  ← 填充色，视觉权重最高
└──────────────┘
┌──────────────┐
│  Secondary   │  ← 描边样式，层级次之
└──────────────┘
┌──────────────┐
│   Ghost      │  ← 幽灵按钮，最弱层级
└──────────────┘
```

## 表单设计

### ✅ 优秀示例：标签对齐与错误处理

**特征：**
- 标签左对齐，位于输入框上方
- 占位符仅作为辅助，不替代标签
- 错误提示紧随输入框下方，红色警示
- 必填项使用 * 标记
- 输入框有明确的焦点状态

**案例：**
```
用户名 *
┌─────────────────────┐
│ 请输入用户名         │
└─────────────────────┘
↑ 焦点状态：蓝色边框

邮箱
┌─────────────────────┐
│ 请输入邮箱          │
└─────────────────────┘
✗ 请输入有效的邮箱地址
```

## 导航设计

### ✅ 优秀示例：清晰的信息架构

**特征：**
- 导航项不超过7个
- 当前页面有明确的视觉指示
- 支持键盘导航
- 移动端有汉堡菜单或底部导航
- 导航项使用动词或名词

**案例：**
```
┌─────────────────────────────────────┐
│ Logo    首页  产品  关于  联系我们  │
│                ↑                    │
│             当前页标识              │
└─────────────────────────────────────┘
```

## 卡片设计

### ✅ 优秀示例：视觉平衡与可扫性

**特征：**
- 卡片有统一的圆角和阴影
- 内容对齐网格系统
- CTA按钮位置一致
- 悬停有微交互反馈
- 标题简洁，不超过2行

**案例：**
```
┌───────────────────────────┐
│  ┌─────────────────────┐  │
│  │      产品图片        │  │
│  └─────────────────────┘  │
│  产品名称                  │
│  产品描述文字（限2行）     │
│              [了解更多] → │
└───────────────────────────┘
```

## 空状态设计

### ✅ 优秀示例：引导而非空白

**特征：**
- 使用插图或图标缓解空白焦虑
- 提供清晰的下一步行动
- 文案友好，不指责用户
- 包含快捷操作入口

**案例：**
```
     ┌─────────────────┐
     │                 │
     │    [插图]       │
     │                 │
     │  还没有订单      │
     │  去选购心仪商品吧 │
     │                 │
     │  [开始购物] →    │
     └─────────────────┘
```

## 加载状态

### ✅ 优秀示例：感知进度与安抚等待

**特征：**
- 使用骨架屏而非spinner
- 加载内容有轮廓占位
- 提供加载进度百分比
- 长时间加载有取消选项

**案例：**
```
┌─────────────────────────┐
│  ┌─────────────────┐   │
│  │ ████████████░░░ │ 45%│
│  └─────────────────┘   │
│  正在加载产品列表...     │
└─────────────────────────┘
```

## 错误处理

### ✅ 优秀示例：建设性错误提示

**特征：**
- 使用友好语气，不指责用户
- 明确说明问题所在
- 提供具体的解决方法
- 保留用户已输入的内容

**案例：**
```
┌─────────────────────────────────┐
│  ⚠ 网络连接失败                 │
│                                 │
│  无法保存您的更改。请检查网络    │
│  连接后重试。                   │
│                                 │
│  [重试]    [取消]               │
└─────────────────────────────────┘
```

## 移动端设计

### ✅ 优秀示例：拇指友好的交互区

**特征：**
- 底部导航用于高频操作
- 可点击目标至少48x48dp
- 手势操作有视觉提示
- 避免边缘内滑动触发系统操作

**案例：**
```
┌─────────────────────┐
│                     │
│     内容区域         │
│                     │
│                     │
├─────────────────────┤
│  🏠  📦  🔍  👤    │
│  首页  订单  搜索  我的  ← 底部导航
└─────────────────────┘
```
